# LeadStream

Premium WordPress attribution plugin by Timberbrook Marketing. Captures UTMs, click IDs, and referrer data; fills form hidden fields; and (Pro) pushes offline conversions back to ad platforms.

## Status

Phase 0 (Foundation). Not yet published. See `PROJECT_PLAN.md` for roadmap.

## Requirements

- WordPress 6.0+
- PHP 7.4+
- Composer (for development)

## Development

```bash
cd plugin
composer install
vendor/bin/phpunit
vendor/bin/phpcs
```

See `docs/dev-setup.md` for Local by Flywheel setup.
